# Balanced Blog CTA Design

## Goal

Make the next step on every guide clear without turning the Ratgeber into a sales funnel full of repeated buttons.

## Approved CTA rhythm

- Keep the existing landing-page and service-page CTA frequency unchanged.
- Keep the existing header booking action and conditional mobile booking action.
- Add one contextual treatment link inside each guide after the second content section.
- Use the article's existing `primaryService` destination and label so each link stays relevant to the topic.
- Keep one strong booking CTA at the end of every guide.
- Add a recognizable WhatsApp icon to the final guide booking button.
- Do not add WhatsApp buttons between sections, duplicate sticky actions, pop-ups, or repeated promotional blocks.

## Presentation

The contextual treatment link is a quiet inline editorial callout, not a filled button. It should use the existing rule-line and text-link visual language.

The final booking action remains the single prominent guide CTA. The WhatsApp icon sits beside the label, uses the current text color, and does not introduce WhatsApp green into the Rosé Modernism palette.

## Accessibility

- The icon is decorative and hidden from assistive technology.
- Button text continues to describe the action without relying on the icon.
- Existing 44-pixel minimum touch-target rules remain intact.

## Verification

- Every guide contains exactly one contextual service CTA.
- Every guide contains one final WhatsApp booking CTA with the icon.
- No guide displays a public price.
- Mobile and desktop pages have no horizontal overflow.
- Production build and responsive UI verification pass.
